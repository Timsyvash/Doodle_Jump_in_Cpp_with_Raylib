# Doodle Jump in C++ (Raylib)

Клон класичної гри **Doodle Jump**, написаний мовою C++ з використанням графічної бібліотеки [Raylib](https://www.raylib.com/).

## 🎮 Особливості гри
- 🟢 **Класичний геймплей**: гравець стрибає по платформах угору.
- 🟤 **Типи платформ**:
  - *Звичайні (зелені)* — безпечні платформи для відштовхування.
  - *Коричневі (крихкі)* — ламаються при наступанні, гравець падає крізь них з анімацією уламків.
- 🔄 **Безкінечний екран**: гравець може залітати за лівий край екрана і з'являтися з правого.
- 🖼️ **Спрайти та графіка**: завантаження текстур персонажа, платформ і фону.

## 🛠️ Вимоги та залежності
- C++17 або новіший.
- Visual Studio 2019 / 2022 (або будь-яка інша IDE з підтримкою C++).
- Бібліотека **Raylib** (версії 4.0+).
